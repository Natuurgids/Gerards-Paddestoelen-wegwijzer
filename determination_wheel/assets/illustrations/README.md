# Diagnostic illustration specification

Illustrations in this directory must depict the character being determined, not merely a representative mushroom.

Required sets:

1. `fruitbody_*` — cap+stem, puffball/belly form, wood/bracket/crust, other form.
2. `hymenium_*` — true gills, tubes/pores, teeth/spines, folds/ridges.
3. `cap_surface_*` — smooth, fibrillose, scaly/warty, viscid/slimy.
4. `gill_attachment_*` — free, attached, decurrent; side section with identical stem/cap geometry so the attachment itself is the variable.
5. `velum_*` — annulus, volva, both, none visible.
6. `hygrophanous_*` — same cap wet versus drying, showing the colour-zone transition.
7. `spore_print_*` — white/cream, pink, brown/rust, purple-brown/dark classes.
8. `bruise_*` — pore/flesh before and after pressure/cutting.
9. `stem_surface_*` — reticulate, scabrous/dotted, smooth.
10. `ecology_*` — soil/litter, wood, grass, dung and host-tree association cues where supported by the determination data.

Use simple botanical/mycological field-guide line art with neutral backgrounds and no decorative species-specific details unless the illustration is explicitly a terminal taxon plate. Each plate needs a data key matching the determination option that invokes it.
